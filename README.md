# 🚀 GUIDE ET SYSTÈME DE CRÉATION DE SITE - SUPER PROMPT

Bienvenue dans le système de création de sites web et d'applications SaaS cinématographiques **1:1 Pixel Perfect**.

Ce dossier est entièrement configuré avec les directives et compétences du **Super Prompt**. Tout nouveau projet ou site créé dans ce dossier (ou sous-dossiers) appliquera automatiquement ces standards d'excellence.

## 🛠️ COMMENT UTILISER CE SYSTÈME DANS N'IMPORTE QUEL DOSSIER DE SITE ?

### 1. Dans ce dossier courant (`c:\Users\costc\Downloads\CREATION DE SITE`)
Les règles sont déjà actives ! Demandez simplement à l'agent :
- *"Construis une landing page cinématographique pour [nom de votre projet]"*
- *"Construis un CV en ligne pour [votre nom]"*
- *"Crée le SaaS de facturation iziFacture"*
- *"Effectue un audit de sécurité de mon projet"*

L'agent posera automatiquement les 4 questions de cadrage via le modal interactif `ask_question`, puis construira le projet de A à Z.

### 2. Pour créer un NOUVEAU dossier de site ailleurs sur votre ordinateur
Pour appliquer ces règles à un autre dossier, il vous suffit de copier le dossier `.agents` et le fichier `AGENTS.md` ou `GEMINI.md` dans la racine de votre nouveau dossier :

```bash
# Exemple de copie des règles vers un nouveau projet :
cp -r .agents /chemin/vers/votre-nouveau-site/
cp AGENTS.md /chemin/vers/votre-nouveau-site/
cp GEMINI.md /chemin/vers/votre-nouveau-site/
```

## 🛡️ EXIGENCE QUALITÉ & ZÉRO PATTERNS GÉNÉRIQUES D'IA

- **Bruit SVG Inline** `<feTurbulence opacity="0.04">` pour éliminer le rendu plat.
- **Boutons Magnétiques** avec `scale(1.03)` et transition `<span>` glissante.
- **GSAP Context** pour un nettoyage parfait du DOM sans fuite mémoire.
- **Typographie à fort contraste** (H1 Sans-Serif massif + Serif Italique dramatique).
- **Vraies images Unsplash** sélectionnées avec précision.
